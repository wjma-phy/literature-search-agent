1. 检索 → 本窗口「即时检索」直连免费 API 筛方向window
2. 富集摘要 → 终端: abstract "标题或 DOI" --prettyterminal
3. 引用扩展 → 终端: cited-by <DOI> --limit 25terminal
4. OA PDF → 终端: pdf <DOI>（下载到 ./pdfs/）→ extract 提全文terminal
5. 归档 Zotero → 终端: zotero-auth → zotero-save <DOI> --note "<p>笔记</p>"terminal

密钥与配额约定（只走环境变量，不入库）

      

        
变量作用设值示例（PowerShell）

        
LIT_SEARCH_MAILTOOpenAlex polite pool / Crossref / Unpaywall 共用邮箱（推荐配置）setx LIT_SEARCH_MAILTO "you@example.com"

        
LIT_SEARCH_OPENALEX_API_KEYOpenAlex 账户额度→10 rps；无则用 mailto 池再退匿名池setx LIT_SEARCH_OPENALEX_API_KEY "…"

        
LIT_SEARCH_S2_API_KEYSemantic Scholar 独享 1 rps（无 key 匿名池 429 频发）setx LIT_SEARCH_S2_API_KEY "…"

        
LIT_SEARCH_ZOTERO_KEYZotero 持久写 key（zotero-auth 弹窗点「始终允许」获得）setx LIT_SEARCH_ZOTERO_KEY "…"

        
LIT_SEARCH_ZOTERO_URLZotero 本地 API 地址（默认 http://localhost:23119/api）setx LIT_SEARCH_ZOTERO_URL "http://localhost:23119/api"

      

      
setx 写入后对之后新开的终端生效；当前终端请用 $env:VAR="值"。
